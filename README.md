# 🐾 LAPA Grooming Salon

**LAPA Grooming Salon** — адаптивное веб-приложение для груминг-салона с формой онлайн-записи, серверной обработкой данных и административной страницей для просмотра заявок.

Проект выполнен в рамках учебной практики.

## Онлайн-версия

Сайт:  
http://grooming-lapa.great-site.net/

Админ-панель:  
http://grooming-lapa.great-site.net/admin.php

## Возможности

- просмотр информации о груминг-салоне;
- просмотр услуг и цен;
- выбор услуги из карточки;
- отправка заявки на онлайн-запись;
- сохранение заявки в базу данных;
- просмотр заявок в административной панели.

## Функциональность

### Главная страница

Содержит:

- главный экран;
- раздел «О нас»;
- блок с услугами;
- контактную информацию;
- форму онлайн-записи.

### Онлайн-запись

Форма собирает данные клиента и питомца:

- имя владельца;
- телефон;
- имя питомца;
- тип питомца;
- порода;
- услуга;
- дата и время записи;
- комментарий.

После отправки данные обрабатываются на PHP и сохраняются в базу данных.

### Административная страница

Страница `admin.php` позволяет просматривать все отправленные заявки в виде таблицы.
